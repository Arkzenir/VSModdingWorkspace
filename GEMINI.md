# Vintage Story Modding Harness

All instructions for this project live in **[AGENTS.md](./AGENTS.md)**.

Read that file first and follow it. This file exists only so that agents looking for
this specific filename still find their way there. It is intentionally not a second
copy: duplicated instructions drift apart and start contradicting each other.

Two rules worth repeating up front, because getting them wrong is costly:

- Only edit files under `workspaces/<active>/mod/`. Everything else is reference
  material or shared cache.
- Never push, add a remote, or open a PR. This harness develops mods only; the user
  copies the finished repo out and publishes it by hand. Local commits are fine.
